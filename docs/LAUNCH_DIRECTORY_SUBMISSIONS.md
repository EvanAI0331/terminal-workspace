
Long description:

```text
Terminal Workspace is an open-source macOS desktop app for developers who keep too many terminal windows open.

It gives each project its own workspace, creates real local PTYs only when started, saves multiline launch commands per terminal, restores stopped terminal metadata after restart, and includes a manual Project Inspector for scripts, env files, workflows, docs, and service markers.

It is not a shell replacement. It is a project-aware desktop control surface around the shells developers already run.
```
